#  Data Analytics Gym

This repository is my practice environment for developing fluency, confidence, and stronger problem-solving habits in data analytics.

Unlike my portfolio projects, which focus on completed analyses and deliverables, the Data Analytics Gym is focused on **practice, repetition, experimentation, and learning from mistakes**.

##  Purpose

The goal of this repository is to strengthen my ability to think and work like a data analyst through regular hands-on practice.

Areas of focus include:

- SQL problem solving
- Python and Pandas
- Data validation
- Business question translation
- Analytical reasoning
- Troubleshooting and debugging
- Communicating findings clearly

##  Repository Structure

### `sql/`
SQL practice problems ranging from foundational queries to more complex analytical patterns.

Current areas of emphasis include:

- `GROUP BY` and aggregation
- CTEs and subqueries
- Window functions
- Ranking
- Running totals
- Percent-of-total calculations
- Multi-step business questions

### `python/`
Python and Pandas exercises used to strengthen data manipulation and analysis skills, including translating SQL concepts into Python workflows.

### `validation/`
Exercises and notes focused on validating analytical results using methods such as:

- Independent calculations
- Excel
- PivotTables / Power Pivot
- Row-count and duplicate checks
- Reconciliation between tools
- Business-logic checks

##  Training Philosophy

The goal is not simply to produce the correct answer.

For each exercise, I want to practice:

1. Understanding the business question
2. Identifying the required data
3. Building the analysis
4. Checking whether the result is correct
5. Explaining what the result means
6. Learning from mistakes and improving the approach

Mistakes are part of the training data.

##  Current Focus

Building stronger intermediate SQL fluency, particularly combining:

**GROUP BY → CTE/Subquery → Window Functions → Validation**

The long-term goal is to become faster and more confident at solving unfamiliar analytical problems without relying heavily on step-by-step guidance.
